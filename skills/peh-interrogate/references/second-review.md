# Second review handoff

Use a genuinely new session of the other installed CLI, or a supported fresh agent with the actual reported model. Default to manual cross-CLI handoff to avoid hidden costs and provider assumptions. A same-model agent is fresh context, not cross-model review.

Give the blind reviewer only this task-local packet:

> Use peh-review to review REPOSITORY at BASE_SHA…HEAD_SHA [plus the explicit local-change scope]. Intended behavior: CONTRACT_OR_SHORT_INTENT. Read applicable repository instructions and inspect source afresh. Return concrete regressions with file:line paths and evidence. Do not edit code, publish comments, or merge. Do not read existing review reports or implementation conversation.

Supply exact values, not placeholders, in a real handoff. If instructions, source, or permissions are unavailable, disclose the resulting limit. Do not assert a specific Codex or Claude model unless the host confirms it.

Once the blind pass finishes, give the synthesizer both sets of findings and their revision snapshots. Let code and falsifiable checks resolve disagreement. Do not use majority voting or a fixed agent team as a substitute for evidence.
